# RepoRogue Test Lab

This repository is generated from the Gimtrist RepoRogue Admin Area.

Its purpose is to exercise the optional repository-authored room contract in `.reporogue/reporogue.yaml`. RepoRogue remains playable without this file; when present, the manifest augments or directs room generation.

## Included authoring tests

- custom room palette and mood
- custom feature
- custom Bug encounter
- custom trap
- custom treasure
- lore
- character-influence hints
- procedural content retained alongside authored content
